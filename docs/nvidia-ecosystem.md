# NVIDIA ecosystem evaluation

LogicScout's NVIDIA dependency that is actually used: **Nemotron models served by Nebius Token Factory** (OpenAI-compatible API).
Everything else below was evaluated on 2026-10-30 from official pages. Nothing else is integrated; no claim here goes beyond what was read.
This machine has no NVIDIA GPU tooling (`nvidia-smi` not found), no Docker/Ubuntu verified, so GPU/Linux-only stacks are blocked locally.

| Item | What it is (source) | Free + within hours? | Would it help LogicScout? | Outcome |
|---|---|---|---|---|
| Nemotron 3 family | Open models Nano (31.6B total / 3.2B active), Super, Ultra; page lists "granular reasoning budget control at inference time" and says Nano and Ultra are released, Super unconfirmed on that page ([research.nvidia.com](https://research.nvidia.com/labs/nemotron/Nemotron-3)) | Used already via Nebius (paid by credits already held; not re-verified here which sizes Nebius serves) | Yes: it is the model runtime | Integrated (existing `logicscout/llm`, not part of this task); model list on Nebius not verified |
| NemoClaw | Apache-2.0 alpha reference stack running OpenClaw/Hermes/LangChain agents inside OpenShell sandboxes ([github.com/NVIDIA/NemoClaw](https://github.com/NVIDIA/NemoClaw)) | Source free; express install targets DGX or WSL; Docker/Ubuntu required per secondary sources | Would sandbox *agent processes*; LogicScout's worlds are in-process simulations with a WorldPort boundary, so little gain | Evaluated and not integrated: alpha, needs WSL/Docker host not verified here, solves agent-runtime isolation we do not have |
| OpenShell | Sandbox runtime NemoClaw runs agents in (same repo page; no further description there) | As above | Possible secure-execution layer for compiled playbooks, but our playbooks run in a restricted DSL, not arbitrary code | Evaluated and not integrated: DSL whitelist already covers the need; OpenShell docs not read in detail |
| Hermes Agent | Open-source self-improving agent framework by Nous Research; NVIDIA announced support on RTX/DGX Spark (secondary news coverage, e.g. [pulse2.com](https://pulse2.com/nous-research-raises-90-million-from-nvidia-m12-samsung-and-other-investors/)); NemoClaw lists it as a supported agent | Open source; not installed | Would replace our purpose-built investigator loop with a general agent: no benefit | Evaluated and not integrated |
| Cosmos (Predict2) | World foundation models for Physical AI video/world prediction; needs Ampere+ GPU, Linux, CUDA 12.6; repo archived in favor of Predict2.5 ([github.com/nvidia-cosmos/cosmos-predict2](https://github.com/nvidia-cosmos/cosmos-predict2)) | Code free; weights under NVIDIA Open Model License | Our worlds are symbolic state machines, not video | Inaccessible locally: no NVIDIA GPU detected (`nvidia-smi` absent), Linux required |
| GR00T N1.7 | Open VLA model for humanoid manipulation; inference needs 16 GB+ VRAM GPU; backbone is a gated Hugging Face model needing approved access ([github.com/NVIDIA/Isaac-GR00T](https://github.com/NVIDIA/Isaac-GR00T)) | Gated | Not relevant: no robot embodiment in our worlds | Inaccessible: no GPU here and gated HF approval |
| Isaac Lab / Sim | GPU-accelerated robotics RL/IL framework, BSD-3; Isaac Sim parts are proprietary-licensed ([github.com/isaac-sim/IsaacLab](https://github.com/isaac-sim/IsaacLab)) | Free, but needs a large GPU stack | A rover world could be embodied there, but not in hours | Inaccessible locally: no NVIDIA GPU detected; hardware requirements not stated on the README (not verified) |
| Jetson deployment | Edge dev kits (AGX Thor, Orin Nano Super, AGX Orin) ([developer.nvidia.com](https://developer.nvidia.com/embedded/jetson-developer-kits)) | No: hardware purchase; prices not listed on the page | Could run a compiled playbook at the edge, a nice story only | Inaccessible: requires buying hardware (spending forbidden) |
| NeMo Guardrails | Open-source toolkit adding programmable rails to LLM apps; `pip install nemoguardrails`, Python 3.10-3.13 ([PyPI](https://pypi.org/project/nemoguardrails), [docs](https://docs.nvidia.com/nemo/guardrails/latest/get-started/installation-guide)) | Pip-installable, free; not installed or tested by us | Marginal: our output safety is already enforced by schema validation + DSL whitelist; would add a heavy dependency tree | Evaluated and not integrated: not small; no demonstration performed |
| NVIDIA NIM | Containerised inference microservices ([docs](https://docs.nvidia.com/nim/large-language-models/latest/introduction.html)); page content could not be retrieved, so free-tier terms are unverified | Unverified | Same role as Nebius Token Factory, which we already use | Evaluated and not integrated: duplicates Nebius runtime; self-hosting needs GPU; terms unverified |

## Notes
- No component was installed or demonstrated, so nothing is claimed as "integrated and demonstrated". `logicscout/nvidia/` was not created.
- Some claims (Hermes, sandbox install requirements) rest on secondary sources, flagged above.
